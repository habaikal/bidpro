## 🚀 **배포 방법 (3가지 선택)**

### 🔥 **방법 1: GitHub + Vercel (가장 쉬움)**
```bash
# 1. GitHub 저장소 생성
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/yourusername/bid-automation-platform.git
git push -u origin main

# 2. Vercel에서 GitHub 저장소 연결
# - vercel.com 접속 → New Project → GitHub 저장소 선택
# - 자동 배포 완료!
```

### ⚡ **방법 2: Vercel CLI (빠름)**
```bash
# 1. Vercel CLI 설치
npm install -g vercel

# 2. 프로젝트 폴더에서 배포
vercel

# 3. 프로덕션 배포
vercel --prod
```

### 🤖 **방법 3: 자동 스크립트 (가장 편함)**
```bash
# 실행 권한 부여 (Linux/Mac)
chmod +x deploy.sh

# 배포 실행
./deploy.sh
```
